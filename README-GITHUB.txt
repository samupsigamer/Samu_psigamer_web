2. Sustituye TU_NUMERO en index.html por el número de WhatsApp sin +, espacios ni guiones.
3. Sustituye TU_EMAIL por tu email real (aparece en mailto y texto visible).
4. Activa GitHub Pages desde Settings > Pages > Deploy from branch > main > /root.
