# Modelo 3 — Recursos interactivos

## Estructura
- `index.html`: web principal.
- `styles.css`: estilos completos.
- `assets/cta-contacto.png`: imagen usada en el CTA.
- `recursos/gaming.html`: lectura de Gaming.
- `recursos/infancia.html`: lectura de Infancia.
- `recursos/familias.html`: lectura para Familias.

## Añadir nuevos artículos o archivos
En la sección `05 · DIVULGACIÓN` de `index.html`, cada tarjeta es un enlace. Puedes cambiar su `href` por un PDF, imagen, documento o nueva página HTML.

Ejemplo:
`href="recursos/mi-articulo.html"`

Para un PDF:
`href="assets/mi-documento.pdf"`

## WhatsApp
Sustituye `TU_NUMERO` en el enlace de WhatsApp por el número internacional sin `+`, espacios ni guiones.
