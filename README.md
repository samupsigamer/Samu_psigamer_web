# Samu Psicólogo — GitHub Pages

Web estática responsive con estética anime/chibi, paleta crema + morado + azul marino y enfoque en psicología infantil, adolescencia y tecnología.

## Publicar en GitHub Pages
1. Crea un repositorio.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. Ve a **Settings → Pages**.
4. Selecciona la rama principal y `/ (root)`.
5. Guarda.

Antes de publicar, sustituye `tuemail@ejemplo.com` por tu email profesional.
